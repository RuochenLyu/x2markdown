# 排障说明

## 右键菜单里没有出现“复制为 Markdown”

可能原因：

- 插件没有成功加载
- 当前页面不是 `http/https` 普通网页
- 当前页面是浏览器内置页、扩展页或其他受限页面
- service worker 没有成功注册或右键菜单没有创建

排查方法：

1. 打开 `chrome://extensions`，确认 `X2Markdown` 已启用。
2. 确认当前页面是普通 `http/https` 网页，而不是 `chrome://`、Chrome Web Store、扩展页或 PDF 查看器。
3. 如果在 `x.com` 信息流中使用，确认右键点在目标帖子卡片内，而不是页面留白、导航区或弹层外部。
4. 在扩展页点击一次“重新加载”，再刷新当前页面重试。
5. 在扩展详情页检查 service worker 是否正常运行。

## 点击后提示“未识别为文章，请选中内容后重试”

可能原因：

- 当前页面是首页、聚合页、导航页、产品页，不是正文页
- 页面正文主要在 iframe 内
- 页面只渲染了壳，没有渲染出正文
- 当前页面更适合复制局部内容，而不是整页正文

处理建议：

1. 先手动选中正文区域，再右键执行“复制为 Markdown”。
2. 滚动页面，等待正文完全渲染后重试。
3. 如果页面内容来自 iframe 或登录后异步加载，先确认正文已经真实出现在当前文档里。
4. 如果稳定复现，优先使用选区模式作为兜底。

## 点击后提示“请在目标帖子卡片内右键后重试”

可能原因：

- 当前页面是 `x.com` 时间线、列表或搜索页
- 右键位置没有命中目标帖子卡片
- 目标帖子刚被虚拟列表回收

处理建议：

1. 先把目标帖子完整滚动到可见区域。
2. 在帖子正文区域内重新右键，而不是在空白处、外层容器或弹层上右键。
3. 如果是帖子详情页，直接在主内容区域右键即可。

## 点击后提示“复制失败，请手动重试”

可能原因：

- 浏览器阻止了当前上下文的剪贴板写入
- 页面焦点异常
- 回退方案 `execCommand('copy')` 也没有成功

处理建议：

1. 关闭页面上的其他弹窗后重试。
2. 在同一页面重新右键，再次执行“复制为 Markdown”。
3. 检查浏览器是否有剪贴板相关限制或安全插件干扰。

## 图片链接不完整或缺失

可能原因：

- 当前内容没有图片
- 图片是懒加载、背景图或 iframe 内容
- `x.com` 改变了图片附件 DOM 结构

处理建议：

1. 确认原内容里确实是普通图片，而不是视频、GIF、背景图或卡片预览。
2. 如果在时间线中测试，确认右键命中的是包含图片的外层帖子卡片。
3. 如果是普通网页，优先选中包含图片说明文字的区域再复制。

## 长文页面复制结果混入无关内容

可能原因：

- X 长文阅读视图结构发生变化
- 某些元信息节点被误判成正文块

处理建议：

1. 先确认是否是受支持的长文页面，包含 `x.com/<user>/article/<id>` 或长文阅读视图形式的 `status` 页面。
2. 检查是否混入了统计数字、作者区或推荐内容。
3. 如果稳定复现，优先在该页面结构上调整 [`content-x.js`](../content-x.js) 的正文块过滤规则。
